# Задание 1
### Список направлений и расширений (плагинов для Grav), которые могут помочь в реализации направлений

| Направление | Ссылка | Краткое описание и комментарий |
| :--- | :--- | :--- |
| **Обратная связь / Подача заявок** | [Форма `form`](https://getgrav.org/downloads/plugins) | **Описание:** Встроенный официальный плагин для создания и обработки любых типов форм (обратная связь, заявки, регистрация). Позволяет гибко настраивать поля, валидацию и действия после отправки (email, сохранение в файл, перенаправление). <br><br> **Комментарий:** Выбран как стандарт де-факто для Grav, поскольку обеспечивает максимальную гибкость и безопасность. Позволяет создавать формы любой сложности через простой YAML или интерфейс администратора. |
| **Расписание занятий (Лента событий)** | [Grav Timeline](https://github.com/OleVik/grav-plugin-timeline) | **Описание:** Создание упорядоченных временных линий (таймлайнов) с вложением событий. <br><br> **Комментарий:** Идеально подходит для расписания. Можно организовать расписание по дням (таймлайн), а пары — как события внутри. Поддерживает сортировку по дате, кастомизацию шаблонов. Нагляднее обычного списка страниц. |
| **Новости и события с фильтрацией** | Встроенная таксономия Grav | **Описание:** Базовая система Grav для категоризации контента с помощью тегов (`tag`) и категорий (`category`). В панели администратора можно назначать теги страницам, а затем выводить и фильтровать их коллекции. <br><br> **Комментарий:** Выбрано базовое решение, так как для фильтрации новостей и событий не требуется отдельный плагин. Grav позволяет создавать динамические списки материалов, отфильтрованные по нужным критериям, прямо из файла разметки страницы (например, показывать только новости с тегом "Важное"). |
| **База знаний / Учебные материалы** | [Knowledge Base Theme](https://github.com/Perlkonig/grav-theme-knowledge-base) | **Описание:** Специализированная тема (или основа для неё), структурирующая контент в виде иерархической документации с оглавлением, поиском и удобной навигацией между разделами. <br><br> **Комментарий:** Выбрана, так как для базы знаний важна не просто публикация, а организация материалов. Хотя есть и плагины, данная тема предоставляет готовую и оптимальную структуру для "базы знаний" или "учебных материалов", позволяя авторам сосредоточиться на содержании. |
| **Раздел «Частые вопросы (FAQ)** | [Timeline](https://github.com/OleVik/grav-plugin-timeline) | **Описание:** Позволяет создавать иерархические "линии времени" или списки, где каждый элемент (вопрос) имеет заголовок, дату, описание (ответ) и может быть вложен в другой. Идеально подходит для структурированных в хронологическом или тематическом порядке данных. <br><br> **Комментарий:** Несмотря на название, плагин отлично подходит для создания аккордеонов или списков вопросов/ответов. Он позволяет гибко настраивать порядок вывода и вложенность элементов, что удобно для создания структурированного раздела FAQ с категориями вопросов. |

# Задание 2

## Установка плагина

Для выполнения данного задания мною было выбрано направление "Расписание занятий". 
Плагин, который будем устанавливать - Timeline

## Скачивание плагина через панель администратора

Для того, чтобы установить плагин необходимо зайти в панель администратора и в левой колонке выбрать раздел "Plugins". Затем в правом верхнем углу нажать на кнопку добавить - "Add" и найти необходимый нам плагин через поисковую строку.
